# Release boundary

This package mirrors the public Q3 2026 model-level summary release of the Reboot Hub DJI Drone Specs and Used Price Index.

- 43 aircraft model-level aggregates
- 251 public catalog configurations represented in aggregate
- Listed-price observations only
- No customer, supplier, private repair, raw order, or configuration-level inventory data
