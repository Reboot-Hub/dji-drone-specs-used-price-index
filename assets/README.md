# Dataset Visual Assets

These two PNG files are exported from the executed outputs of
`notebooks/q3-2026-listed-price-range-analysis.ipynb` in release `v0.2.0`.
They use only the public CC BY 4.0 model-level aggregate dataset.

## Files

- `configuration-coverage-by-model.png`
  - Alt text: Bar chart of configuration coverage by DJI model in the Q3 2026 listed-price snapshot.
- `listed-price-ranges-top-coverage-models.png`
  - Alt text: Range chart of low, median, and high listed prices for the twelve models with the highest configuration coverage.
